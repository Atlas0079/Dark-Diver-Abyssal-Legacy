# 项目介绍

这是一个基于Godot引擎开发的回合制角色扮演游戏，融合了搜刮、战斗与撤离机制。游戏采用自动战斗系统，战斗机制借鉴了《圣兽之王》。玩家将扮演一名冒险者，率领小队进入随机生成的地下城，劫掠财宝并成功撤离。

## 核心玩法
- **自动战斗**：基于角色属性、技能和状态的回合制战斗系统
- **资源管理**：管理小队成员的生命值、法力值和其他资源
- **风险决策**：决定是否继续探索或带着已获得的宝藏撤离
- **队伍构建**：通过招募不同职业的角色组建最优小队

## 开发进度
- **已完成**：单场战斗的完整逻辑，包括技能系统和状态效果
- **进行中**：根据战斗事件列表生成对话和叙事内容

# 游戏系统

## 战斗系统
战斗基于回合制自动战斗机制，每个角色根据其行动阈值积累行动点，达到阈值后执行行动。战斗包含主动技能、被动技能和状态效果三种主要事件类型。


## 角色成长
角色可以通过升阶来提升职业等级。高阶职业会解锁新的技能，并提供少量属性加成。设计的核心理念是让升级带来新的战术选择和策略深度，而非简单的数值膨胀。

## 数值系统
角色的核心战斗数值主要由装备和熟练度决定：
- **装备**: 决定角色属性的基础范围，即属性的上限和下限。
- **熟练度**: 影响角色在战斗中实际发挥的水平，高熟练度使角色表现更趋近其装备所提供的属性上限。

## 地下城系统
计划实现基于程序生成的随机地下城，包含不同区域、房间和通道。玩家需要在探索与撤离之间做出选择，越深入风险和奖励越高。

地下城并非一成不变，它会在游戏内时间流逝一段周期后（例如4-6场战斗后）进行**重置**。重置会彻底改变地下城的结构布局、怪物分布、事件遭遇和宝藏位置。

**地图系统**与地下城重置紧密相关：
-   玩家可以从冒险者工会购买已探索区域的地图。
-   然而，在地下城**重置初期**，可购买的地图非常有限，且通常只覆盖奖励较低的区域（因为这些区域最先被其他冒险者探索和绘制）。这段时间，地下城深处未被探索的区域奖励最为丰厚，但也意味着更高的风险和未知性。
-   随着时间推移，到了**重置中后期**，工会会收购到更多由其他冒险者绘制的详细地图。这些地图能提供更精确的信息，帮助玩家规划路线，但也意味着地图上标记的区域可能已被多次搜刮，奖励相对减少。
-   玩家也可以将在探索中绘制的**地图上交给工会**，根据地图的详细程度、覆盖区域的价值以及提交时距离重置的时间点来获得报酬。这不仅是一种收入来源，也是玩家在探索失败、资金耗尽时重新获取启动资金的途径。

此外，地下城拥有**多个入口**。玩家每次进入时，可以选择从不同的入口开始探索。不同的入口会通往特性各异的区域，这些区域在敌人种类、环境特点、随机事件、潜在奖励和房间分布逻辑上都会有所不同，为玩家提供了多样化的起点选择和重复探索价值。

## 任务系统
游戏包含多种类型的任务：
- **主线任务**: 推动游戏核心剧情发展的任务。
- **支线任务**: 在探索过程中可能遇到的可选任务，通常有较长的故事线，但一般不直接影响主线结局。
- **委托任务**: 程序生成的短时效任务，剧情较少，通常是完成特定目标（如击败特定敌人、收集特定物品）。委托可以来源于冒险者工会或其他游戏内事件（如地下城中的随机遭遇）。

## 动态世界与派系冲突

随着游戏内时间的推移，玩家将观察到世界局势的动态演变，特别是不同派系之间紧张关系的逐步升级。这些冲突并非仅仅是背景叙事，它们将对游戏世界产生实质性的影响。

玩家在面对这些不断变化的局势时，拥有选择的权力：可以选择积极介入，支持某一派系，或是保持中立，置身事外。然而，不采取行动本身也是一种选择，同样会带来相应的后果。

玩家的每一个决策都将对其与各派系的关系产生直接影响。例如：
*   **积极介入**：帮助某个派系可能会解锁该派系独有的服务、商品、任务或特殊奖励，但同时可能导致与敌对派系的关系恶化，从而失去或减少从后者获得帮助的机会。
*   **保持中立**：虽然可能避免直接的敌对关系，但也可能错失因支持特定派系而带来的独特优势。在某些情况下，中立甚至可能被所有派系视为不可靠。

这种设计旨在让玩家深刻体验到其行为对游戏世界产生的真实、可感知的改变。玩家的选择不仅塑造了故事的走向，更直接影响了可用的游戏机制和资源，从而带来更具沉浸感和策略深度的游戏体验。

## 动态市场

游戏内的市场经济并非一成不变，而是会受到一系列**隐藏的游戏变量和世界事件**的影响而动态波动。例如：
*   某地区爆发战争或冲突时，武器、防具和治疗药剂的价格可能会上涨。
*   丰收的季节，粮食类商品的价格可能会下降。
*   特定的灾害（如瘟疫、矿难）可能会导致相关资源（如药材、矿石）短缺，价格飙升。

这种动态市场机制鼓励玩家关注世界动态，把握时机进行交易，从而获取更大利润或以更低成本获取所需物品。

## 集会系统

随着玩家声望的提升和队伍的壮大，可招募的冒险者数量会逐渐超过单个小队（默认上限6人）的容量。此时，玩家将有机会建立属于自己的**集会**（或称公会、据点）。

建立集会需要满足特定条件，通常包括：
*   **购置房产**：玩家需要花费资金购买或租赁一处合适的地点作为集会总部。
*   **建设与升级**：玩家可以使用从地下城探索中获得的材料，或是直接购买的资源，来建设和升级集会内部的各种设施（如训练场、炼金室、工坊等）。

集会的主要功能包括：
*   **管理闲置成员**：为超过小队上限的冒险者提供一个"家"。
*   **组建派遣小队**：玩家可以从集会成员中组建额外的冒险小队。
*   **自主探索任务**：派遣这些额外的小队自主前往已解锁的地下城区域进行探索和搜刮。在自主探索期间，玩家无法直接控制这些小队的具体战术和行动决策。
*   **资源供给**：玩家可以为被派遣的小队提供装备、道具和资金支持，以提高他们的成功率和生存能力。
*   **收益共享**：成功完成探索任务的小队会将其获得的一部分战利品和资金上缴至集会，作为集会的运营资金和玩家的额外收入来源。

集会系统为玩家提供了更深层次的队伍管理和资源运作体验，将玩家从单纯的冒险者提升为一支冒险队伍的领导者和管理者。
